# คู่มือการเขียน — ข้อกำหนดของข้อความสำหรับ CPT

เอกสารนี้ไม่ใช่คำแนะนำเชิงศิลปะ แต่เป็น **สเปกทางเทคนิค**
เพราะสิ่งที่ CPT ฝังเข้าไปในน้ำหนักโมเดลคือ *การกระจายทางสถิติของข้อความ*
ทุกรูปแบบที่ปรากฏบ่อยในคลังข้อมูลจะกลายเป็นแนวโน้มที่โมเดลผลิตออกมาภายหลัง

---

## กฎที่ห้ามละเมิด

| # | กฎ | เหตุผลเชิงเทคนิค |
|---|---|---|
| 1 | **ห้ามรูปแบบถาม-ตอบ** ทุกชนิด | ถ้าคลังมี Q&A โมเดลจะเรียนว่า "หลังเครื่องหมายคำถามต้องตามด้วยคำตอบ" ซึ่งทำให้ base model กลายเป็น pseudo-instruct ที่คุณภาพต่ำกว่าการทำ SFT จริงมาก |
| 2 | **ห้าม bullet, เลขข้อ, ตาราง, checklist** | เป็นโครงสร้างเชิงรายการที่ทำให้โมเดลเรียนจะขึ้นบรรทัดใหม่ทุกสองสามคำ ทำลายความสามารถในการเขียนย่อหน้ายาว |
| 3 | **ห้าม markdown ในเนื้อบท** | `**` `##` `` ` `` จะกลายเป็น token ที่โมเดลพ่นออกมาโดยไม่มีเหตุผล |
| 4 | **ห้าม meta-text** | "ในบทนี้เราจะ..." "ดังที่กล่าวไปข้างต้น" "หวังว่าจะเป็นประโยชน์" คือสำนวนผู้ช่วย AI ไม่ใช่สำนวนหนังสือ ถ้าฝังไปจะดึงกลับยาก |
| 5 | **ห้ามพูดกับผู้อ่านตรง ๆ** | "ลองทำดูสิ" "คุณเคยสงสัยไหมว่า" เป็นสำนวน self-help ที่จะกลบสำนวนสารคดีวิทยาศาสตร์ |
| 6 | **ข้อเท็จจริงต้องมาจาก FACT_TABLE.md เท่านั้น** | ข้อมูลผิดที่ถูกฝังเข้าน้ำหนักโมเดลแล้วแก้ไม่ได้ด้วยการ prompt |

## เป้าหมายเชิงปริมาณ

| ตัวชี้วัด | เป้า | ทำไม |
|---|---|---|
| ความยาวประโยค | เฉลี่ย **35–60 คำ** | นี่คือหัวใจของโจทย์ — ต้องการให้โมเดลเรียนโครงสร้างประโยคซ้อนที่ยาว ไม่ใช่ประโยคสั้นห้วน |
| ความยาวย่อหน้า | **180–320 คำ** (4–7 ประโยค) | ย่อหน้ายาวสอนโมเดลให้รักษา coherence ข้ามหลายร้อย token |
| ความยาวบท | **หน้า × 320 คำ** ตาม OUTLINE.md | ให้แต่ละบทยาวเกิน `seq_len` มาก เพื่อให้แต่ละบล็อกที่ pack ได้มาจากบริบทเดียวกัน |
| สัดส่วนอักขระไทย | **> 85%** | ต่ำกว่านี้แปลว่ามีศัพท์อังกฤษเยอะเกิน — ควรทับศัพท์เป็นไทยแทน |
| ศัพท์เทคนิคภาษาอังกฤษ | ≤ 3 คำต่อย่อหน้า | ใส่ได้เมื่อจำเป็น แต่ครั้งแรกให้เขียนไทยแล้ววงเล็บอังกฤษกำกับ ครั้งต่อไปใช้ไทยล้วน |

## โครงสร้างของแต่ละบท

```
บรรทัดที่ 1   :  # บทที่ N ชื่อบท          ← หัวข้อเดียวในไฟล์ (จะถูกแปลงเป็นข้อความธรรมดาตอน clean)
บรรทัดว่าง
ย่อหน้าที่ 1  :  เข้าเรื่องด้วยฉาก ตัวเลข หรือกรณีศึกษาที่เป็นรูปธรรม — ห้ามเกริ่นแบบสรุปสารบัญ
ย่อหน้ากลาง   :  อธิบายกลไก → หลักฐาน → ข้อจำกัดของหลักฐาน → นัยต่อการปฏิบัติ
ย่อหน้าสุดท้าย:  ทอดสะพานไปยังประเด็นของบทถัดไปอย่างเป็นธรรมชาติ ห้ามขึ้นต้นว่า "สรุป"
```

## ตัวอย่างเปรียบเทียบ

### ❌ แบบที่ทำลาย CPT

```
## การสร้างนิสัย

**คำถาม:** ต้องใช้เวลานานแค่ไหน?

การสร้างนิสัยมี 4 ขั้นตอน:
- สิ่งกระตุ้น (Cue)
- ความอยาก (Craving)
- การตอบสนอง (Response)
- รางวัล (Reward)

ในบทนี้เราจะมาดูกันว่า...
```

ปัญหา: หัวข้อย่อย, ถาม-ตอบ, bullet, ตัวหนา, meta-text — ผิดครบทุกข้อ

### ✅ แบบที่ต้องการ

> ความเชื่อที่ว่านิสัยใหม่ต้องใช้เวลายี่สิบเอ็ดวันจึงจะฝังตัวนั้น แพร่หลายจนกลายเป็นสามัญสำนึกในหนังสือพัฒนาตนเองแทบทุกเล่ม ทั้งที่เมื่อสืบย้อนกลับไปถึงต้นตอจริง ๆ แล้วจะพบว่าตัวเลขนี้ไม่ได้มาจากการศึกษาเรื่องนิสัยแม้แต่น้อย หากมาจากข้อสังเกตของศัลยแพทย์ตกแต่งชื่อแม็กซ์เวลล์ มอลตซ์ ซึ่งเขียนไว้ในหนังสือของเขาเมื่อปี 1960 ว่าผู้ป่วยที่เพิ่งผ่านการผ่าตัดเปลี่ยนใบหน้าหรือสูญเสียอวัยวะมักต้องใช้เวลาอย่างน้อยราวยี่สิบเอ็ดวัน กว่าภาพลักษณ์ในใจของตัวเองจะปรับให้เข้ากับร่างกายใหม่ได้ ซึ่งเป็นคนละเรื่องกับการที่พฤติกรรมหนึ่งจะกลายเป็นอัตโนมัติจนไม่ต้องอาศัยความตั้งใจอีกต่อไป
>
> เมื่อมีการวัดเรื่องนี้อย่างเป็นระบบเป็นครั้งแรกโดยฟิลิปปา แลลลีและคณะในปี 2010 โดยติดตามอาสาสมัครที่พยายามสร้างพฤติกรรมใหม่อย่างการดื่มน้ำก่อนอาหารหรือวิ่งก่อนมื้อเย็นเป็นเวลาสิบสองสัปดาห์ สิ่งที่พบกลับไม่ใช่ตัวเลขเดียวที่ใช้ได้กับทุกคน แต่เป็นการกระจายที่กว้างอย่างน่าตกใจ ค่ามัธยฐานอยู่ที่หกสิบหกวันก็จริง ทว่าช่วงที่พบจริงกินตั้งแต่สิบแปดวันไปจนถึงสองร้อยห้าสิบสี่วัน ขึ้นอยู่กับว่าพฤติกรรมนั้นซับซ้อนแค่ไหนและต้องแทรกเข้าไปในกิจวัตรเดิมได้ยากเพียงใด

ลักษณะที่ถูกต้อง: ประโยคยาว 50–70 คำ, อนุประโยคซ้อน, อ้างงานวิจัยกลืนไปในประโยค, ไม่มีสัญลักษณ์ใด ๆ

## คำเชื่อมที่ควรใช้บ่อย

การใช้คำเชื่อมเชิงเหตุผลถี่ ๆ คือกลไกที่ทำให้ประโยคยาวโดยไม่เสียความหมาย

**ขยายความ** — ซึ่ง / อันเป็นผลให้ / กล่าวคือ / นั่นหมายความว่า / โดยเฉพาะอย่างยิ่งเมื่อ
**ขัดแย้ง** — ทว่า / หากแต่ / ในขณะที่ / แม้ว่า...แต่ / ตรงกันข้ามกับที่มักเข้าใจกัน
**เหตุ-ผล** — เพราะเหตุนี้เอง / จึงเป็นเหตุให้ / ด้วยเหตุผลเดียวกันนี้ / ซึ่งอธิบายได้ว่าทำไม
**ลำดับเวลา** — เมื่อ...แล้ว / ก่อนที่จะ / นับตั้งแต่ / ต่อเมื่อ...จึง
**เงื่อนไข/ข้อจำกัด** — เท่าที่หลักฐานปัจจุบันบ่งชี้ / ภายใต้เงื่อนไขที่ว่า / อย่างน้อยก็ในระดับที่วัดได้
